# CLAUDE.md — Overworld

Overworld — a lens and an archive over a *Habitica* account (no affiliation; habitica.com stays the system of record because the mobile widget does). Habitica hard-deletes completed to-dos at 30 days and averages daily history at 60, so `tools/hbx.py` (stdlib Python, launchd-scheduled) snapshots into an append-only deduped JSONL archive and the site keeps an IndexedDB mirror in the same bundle format, mergeable both ways. Zones/areas/horizons/kinds ride on sigil-prefixed tag names (@ + ! ?) because Habitica has no location or custom fields, and the sigil is what clusters each facet inside the phone widget's flat tag list; `hbx plan` proposes a taxonomy but parks ambiguous tags in a review list rather than guessing, and bulk retagging is CLI-only so the diff is a file you read before `--apply`. No backend: Habitica's API is CORS-open, so the browser calls it directly and a meta CSP pins connect-src to habitica.com (overworld.neorgon.com)

**Live:** overworld.neorgon.com · **Port:** 8864

## Run

```bash
make serve
```

Then open http://localhost:8864. It must be served over HTTP — the app is ES modules, and `file://` blocks them.

## Gotchas

- **habitica.com stays the system of record**, because the phone widget does. This
  site is a lens and an archive over the account, never the source of truth.
- Habitica hard-deletes completed to-dos at 30 days and averages daily history at
  60. `tools/hbx.py` snapshots into an append-only deduped JSONL archive for
  exactly that reason — the archive is not a cache, it is the only copy of old data.
- Zones/areas/horizons/kinds ride on **sigil-prefixed tag names** (`@`, `+`, `!`,
  `?`) because Habitica has no location or custom fields. The sigil is what
  clusters each facet inside the phone widget's flat tag list; renaming tags
  without the sigil breaks the widget grouping, not just this site.
- `hbx plan` parks ambiguous tags in a review list rather than guessing, and bulk
  retagging is CLI-only so the diff is a file you read before `--apply`.
- No backend: Habitica's API is CORS-open, so the browser calls it directly and a
  meta CSP pins `connect-src` to habitica.com.
